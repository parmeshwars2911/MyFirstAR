Data Collection and Organisation

Raw Data: Information collected in its original, unorganised form is called raw data. For example, marks scored by 20 students in a test: 45, 32, 67, 45, 78, 32, 45, 56, 67, 78, 32, 45, 90, 56, 67, 78, 45, 32, 56, 67.

Array: Raw data arranged in ascending or descending order is called an array. Arranging the above data in ascending order: 32, 32, 32, 32, 45, 45, 45, 45, 45, 56, 56, 56, 67, 67, 67, 67, 78, 78, 78, 90.

Frequency: The number of times a particular value appears in a data set is called its frequency. For example, the value 45 appears 5 times, so its frequency is 5.

Frequency Distribution Table: A table that displays each data value alongside its tally marks and frequency, making the data easy to read and analyse.

Key Point: The sum of all frequencies must equal the total number of observations (here, 4+5+3+4+3+1 = 20). Tally marks are grouped in sets of five: four vertical lines crossed by one diagonal line (||||) represents 5.

Grouped Data and Class Intervals

When data values are spread over a wide range or there are too many distinct values, we group them into intervals called class intervals to make analysis manageable.

  • Class Interval: A range that groups values together. Example: 10–20 includes values from 10 up to (but not including) 20.
  • Class Size (Width): The difference between the upper and lower boundaries. For 10–20, class size = 20 – 10 = 10.
  • Class Mark (Midpoint): Represents the entire class interval in calculations.
  • Cumulative Frequency: The running total of frequencies from the first class up to the current class.
Class Mark = (Lower Class Limit + Upper Class Limit) / 2

Example: Marks of 30 students in a science test, organised into class intervals of width 10:

Note: The class interval 10–20 includes 10 but not 20. This is called the exclusive method (upper limit excluded). The cumulative frequency for 30–40 is 21, meaning 21 students scored less than 40 marks.

Histograms and Bar Graphs

Bar Graph

  • Used for discrete (separate, countable) data such as categories and named groups.
  • Bars have gaps between them to show that the categories are separate.
  • The width of bars carries no mathematical meaning.
  • X-axis shows category names (e.g., subjects, months, sports).
  • Example: Number of students who prefer each subject.

Histogram

  • Used for continuous (grouped) data organised in class intervals.
  • Bars have no gaps between them because the data is continuous.
  • The width of each bar equals the class size (has mathematical meaning).
  • X-axis shows class interval boundaries (numbers like 0, 10, 20, 30 ...).
  • Example: Heights of students grouped into 5 cm intervals.

Steps to Draw a Histogram

  1. Draw the x-axis (horizontal) and y-axis (vertical) and label them. X-axis shows class intervals; y-axis shows frequency.
  2. Mark the class boundaries on the x-axis at equal distances (e.g., 0, 10, 20, 30, ...). If all class sizes are equal, the spacing is uniform.
  3. Choose an appropriate scale for the y-axis that accommodates the highest frequency.
  4. Draw a rectangle (bar) for each class interval. The height of the bar equals the frequency of that class. Bars must touch each other — there must be no gaps.
  5. Label both axes clearly and write a title above the histogram.

Frequency Polygon: Connect the midpoints of the tops of histogram bars with straight lines. Extend the line to the x-axis at each end. This polygon shows the shape of the data distribution visually.

Important Fact: The area of each bar = class width x frequency. When class sizes are equal, the height alone represents frequency and bars can be compared directly.

Pie Charts / Circle Graphs

A pie chart (also called a circle graph) represents data as sectors of a circle. The full circle represents the total data (100%), and each sector represents one component proportionally. Since a full circle = 360°, each sector's angle is calculated as a proportion of 360°.

Angle of a sector = (Value of component / Total value) × 360°

Worked Example

In a survey of 240 students, their favourite sports were recorded. Calculate each sector angle:

Sport Number of Students Fraction of Total Sector Angle
Cricket6060/240 = 1/4(60/240) × 360° = 90°
Football8080/240 = 1/3(80/240) × 360° = 120°
Basketball4040/240 = 1/6(40/240) × 360° = 60°
Tennis6060/240 = 1/4(60/240) × 360° = 90°
Total240360°

Steps to Draw a Pie Chart

  1. Find the total of all values.
  2. Calculate each sector's angle using the formula above.
  3. Verify: all angles must sum to exactly 360°.
  4. Draw a circle of a convenient radius using a compass.
  5. Draw one radius as a starting reference. Using a protractor, measure and mark each angle in turn, drawing a new radius for each sector.
  6. Label each sector with the category name and its value or percentage.
  7. Give the chart a clear title and use shading or colour to distinguish sectors.

Introduction to Probability

Key Terms and Definitions

  • Experiment: Any action or process that produces an observable result. Example: tossing a coin, rolling a die, drawing a card.
  • Random Experiment: An experiment in which the result cannot be predicted with certainty before it is performed, but all possible results are known. Example: rolling a fair die — we know the result will be 1, 2, 3, 4, 5, or 6, but we cannot say which one in advance.
  • Outcome: A single possible result of an experiment. Tossing a coin has two outcomes: Head (H) or Tail (T).
  • Sample Space (S): The set of all possible outcomes of an experiment. For rolling a die: S = {1, 2, 3, 4, 5, 6}. Total outcomes = 6.
  • Event (E): Any specific outcome or collection of outcomes that we are interested in. Example: "Getting a number greater than 4" is an event = {5, 6}.
  • Favourable Outcomes: The outcomes that satisfy (belong to) the event. For the event "even number on a die": favourable outcomes = {2, 4, 6} = 3 outcomes.
P(E) = Number of favourable outcomes / Total number of outcomes

Important Properties of Probability

  • The probability of any event E is always between 0 and 1: 0 ≤ P(E) ≤ 1
  • P(impossible event) = 0. Example: getting 8 on a standard die (impossible).
  • P(certain event) = 1. Example: getting a number less than 7 on a die (always happens).
  • Complementary Events: P(E) + P(not E) = 1, so P(not E) = 1 – P(E).

Tossing a Coin

Sample Space = {H, T}, Total outcomes = 2

P(Head) = 1/2

P(Tail) = 1/2

P(not Head) = 1 – 1/2 = 1/2

Rolling a Die

Sample Space = {1, 2, 3, 4, 5, 6}, Total = 6

P(getting 4) = 1/6

P(getting even number) = 3/6 = 1/2

P(getting a number > 4) = 2/6 = 1/3

P(getting a prime) = P({2,3,5}) = 3/6 = 1/2

Chapter 5 Summary – Data Handling

Key Definitions

  • Raw Data: Unorganised collected information
  • Array: Data arranged in ascending or descending order
  • Frequency: Number of times a value appears in data
  • Class Interval: A group range for organising data (e.g., 10–20)
  • Class Size: Upper limit minus Lower limit of a class
  • Cumulative Frequency: Running total of frequencies up to a class
  • Histogram: Bar graph for continuous grouped data — no gaps between bars
  • Bar Graph: Chart for discrete data — gaps between bars
  • Pie Chart: Circle divided into sectors representing proportional data

All Key Formulas

Class Mark = (Lower Limit + Upper Limit) / 2
Sector Angle = (Component Value / Total) × 360°
P(E) = Favourable Outcomes / Total Outcomes

Probability Rules

  • 0 ≤ P(E) ≤ 1 for any event E
  • P(E) + P(not E) = 1
  • P(impossible event) = 0
  • P(certain event) = 1

Histogram vs Bar Graph

  • Histogram: no gaps, continuous data, width = class size
  • Bar Graph: gaps present, discrete/categorical data

Quick Check: Verify pie chart angles sum to 360°. Verify all frequency totals match the number of data points. Probability values must always lie between 0 and 1.
