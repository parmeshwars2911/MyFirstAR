Perfect Cubes

The cube of a number n is n × n × n, written as n³. A perfect cube is an integer that can be expressed as the cube of another integer.

The Hardy-Ramanujan Number: 1729

The number 1729 is famous in mathematics. It is the smallest positive integer that can be expressed as the sum of two positive cubes in two different ways:

1729 = 1³ + 12³ = 1 + 1728 = 1729
1729 = 9³ + 10³ = 729 + 1000 = 1729

This property was discovered when the famous British mathematician G.H. Hardy visited the Indian mathematical genius Srinivasa Ramanujan in hospital. Hardy mentioned that he arrived in a taxi with the "dull" number 1729, and Ramanujan immediately pointed out this remarkable property. Numbers with this property are now called taxicab numbers.

Such numbers that can be expressed as the sum of two cubes in multiple ways are called Hardy-Ramanujan numbers.

Properties of Cube Numbers

Parity Property

  • The cube of an even number is always even.
    Example: 4³ = 64 (even), 6³ = 216 (even).
  • The cube of an odd number is always odd.
    Example: 3³ = 27 (odd), 5³ = 125 (odd).

Sign Property

  • The cube of a positive number is positive.
  • The cube of a negative number is negative.
    Example: (−3)³ = −3 × −3 × −3 = −27.
  • The cube of zero is zero: 0³ = 0.

A perfect cube in the prime factorisation always has every prime appearing a multiple of 3 times.

Finding Cube Root by Prime Factorisation

The cube root of a number x is the number y such that y³ = x. It is written as ∛x or x^(1/3).

In a perfect cube, every prime factor appears a number of times that is a multiple of 3 (i.e., in groups of three identical factors).

Method

  1. Find the prime factorisation of the given number.
  2. Group the prime factors into triples (groups of three identical factors).
  3. Take one factor from each triple.
  4. Multiply all the selected factors together — the result is the cube root.

Example 1: Find ∛216

Prime factorisation: 216 = 2 × 108 = 2 × 2 × 54 = 2 × 2 × 2 × 27 = 2 × 2 × 2 × 3 × 3 × 3

216 = 2³ × 3³   so   ∛216 = 2 × 3 = 6

Check: 6³ = 216. Correct.

Example 2: Find ∛3375

3375 = 3 × 1125 = 3 × 3 × 375 = 3 × 3 × 3 × 125 = 3 × 3 × 3 × 5 × 5 × 5

3375 = 3³ × 5³   so   ∛3375 = 3 × 5 = 15

Check: 15³ = 3375. Correct.

Example 3: Find ∛13824

13824 = 2 × 6912 = 2² × 3456 = 2³ × 1728 = 2³ × 12³ (since 1728 = 12³ = 1728, and 12 = 4 × 3 = 2² × 3)

More carefully: 13824 = 2³ × 1728 = 2³ × (2³ × 216) = 2³ × 2³ × 6³

13824 = 2⁶ × 3³ × ... ∛13824 = 24   (since 24³ = 13824)

Checking if a Number is a Perfect Cube

Factorise the number. If every distinct prime factor appears exactly 3 times (or 6 times, 9 times — any multiple of 3), it is a perfect cube. Example: 500 = 2² × 5³. Since 2 appears only twice, 500 is NOT a perfect cube.

Estimation of Cube Roots

When a number is large, we can estimate its cube root by identifying which two consecutive perfect cubes the number lies between, then using the unit digit trick to find the exact cube root.

Method for Estimating ∛n (where n is a 5 or 6 digit number)

  1. Step 1 — Unit digit trick: Look at the unit digit of n. Use the unit digit table (from Slide 3) to find the unit digit of the cube root. (E.g., if n ends in 3, the cube root ends in 7.)
  2. Step 2 — Group the digits: Separate the last three digits from the remaining digits. The remaining digits form the "left group".
  3. Step 3 — Estimate the tens digit (or hundreds digit): Find the largest integer k such that k³ is less than or equal to the left group. This k becomes the leading digit(s) of the cube root.
  4. Step 4 — Combine: The cube root is the two-digit number formed from k (step 3) and the unit digit (step 1).

Worked Example: Find ∛74088

Step 1 — Unit digit: 74088 ends in 8. From the table: unit digit of cube root = 2.

Step 2 — Separate: Last three digits: 088. Left group: 74.

Step 3 — Estimate: Find k such that k³ ≤ 74. We know 4³ = 64 and 5³ = 125. Since 64 ≤ 74 < 125, we have k = 4.

Step 4 — Combine: Cube root = 42.

∛74088 = 42   (check: 42³ = 74088)

Another Example: Find ∛17576

Unit digit of 17576 is 6 → unit digit of cube root is 6.

Left group: 17. Largest k: 2³ = 8 ≤ 17 < 27 = 3³, so k = 2.

∛17576 = 26   (check: 26³ = 17576)

Example: Find ∛91125

Unit digit of 91125 is 5 → unit digit of cube root is 5.

Left group: 91. Largest k: 4³ = 64 ≤ 91 < 125 = 5³, so k = 4.

∛91125 = 45   (check: 45³ = 91125)

Cube Roots of Negative Numbers and Fractions

Cube Roots of Negative Numbers

Unlike square roots, cube roots of negative numbers are defined and are negative. This is because the cube of a negative number is negative:

∛(–a) = –∛a   (for any positive number a)

This follows from the fact that (–y)³ = –y³. So if y³ = a, then (–y)³ = –a, meaning ∛(–a) = –y = –∛a.

Examples of Cube Roots of Negative Numbers

  • ∛(–8) = –∛8 = –2   (since (–2)³ = –8)
  • ∛(–27) = –∛27 = –3   (since (–3)³ = –27)
  • ∛(–125) = –∛125 = –5   (since (–5)³ = –125)
  • ∛(–1000) = –∛1000 = –10   (since (–10)³ = –1000)
  • ∛(–343) = –∛343 = –7   (since (–7)³ = –343)

Cube Roots of Fractions

For a fraction p/q, the cube root is found by taking the cube root of numerator and denominator separately:

∛(p/q) = ∛p / ∛q

Examples

  • ∛(8/27) = ∛8 / ∛27 = 2/3   (check: (2/3)³ = 8/27)
  • ∛(1/64) = ∛1 / ∛64 = 1/4   (check: (1/4)³ = 1/64)
  • ∛(27/125) = ∛27 / ∛125 = 3/5   (check: (3/5)³ = 27/125)
  • ∛(–64/125) = –∛(64/125) = –4/5   (since (–4/5)³ = –64/125)
  • ∛(216/343) = ∛216 / ∛343 = 6/7   (check: (6/7)³ = 216/343)

Combined Rule

For negative fractions, combine both rules:

∛(–p/q) = –∛p / ∛q

Key Contrast with Square Roots

  • √(–4) is NOT a real number (undefined in real numbers).
  • ∛(–8) = –2 IS a real number.
  • Cube root is defined for all real numbers; square root is defined only for non-negatives.
