Algebraic Expressions and Identities

Chapter 9 · Grade 8 Mathematics

Expressions built from variables and constants, combined using the four operations.

Topics covered: Terms · Factors · Coefficients · Types of polynomials · Addition & subtraction · Multiplication · Standard algebraic identities

Terms, Factors, and Coefficients

Key Vocabulary

Expression: A combination of variables, constants, and operations. Example: 3x² + 5xy − 7

Term: Parts of an expression separated by + or −. The expression above has 3 terms: 3x², 5xy, −7.

Factor: Each quantity multiplied together in a term. Factors of 5xy are 5, x, and y.

Coefficient: The numerical factor of a term. Coefficient of 3x² is 3; coefficient of 5xy is 5.

Types of Polynomials

Monomial: One term only. Examples: 4x, −7y², 9.

Binomial: Exactly two terms. Examples: x + 3, a² − b².

Trinomial: Exactly three terms. Example: x² + 3x + 2.

Polynomial: General term for expressions with one or more terms.

Like terms: Terms with the same variable part. 3x² and −5x² are like terms; 3x² and 3x are unlike terms.

Degree of a polynomial = highest power of the variable. Degree of 4x³ − 2x + 1 is 3.

Addition and Subtraction of Algebraic Expressions

Only like terms can be added or subtracted. Unlike terms remain separate.

Addition Example

Add 3x² + 5x − 2 and x² − 3x + 7

Group like terms:

(3x² + x²) + (5x − 3x) + (−2 + 7)

= 4x² + 2x + 5

Column Method

3x² + 5x − 2

+ x² − 3x + 7

─────────────

4x² + 2x + 5

Subtraction Example

Subtract 2a − b + 3c from 5a + 2b − c

Change sign of each term being subtracted:

(5a + 2b − c) − (2a − b + 3c)

= 5a + 2b − c − 2a + b − 3c

= (5a − 2a) + (2b + b) + (−c − 3c)

= 3a + 3b − 4c

Key Rule

When subtracting, change the sign of every term in the expression being subtracted.

Multiplication of Algebraic Expressions

Monomial × Monomial

Multiply coefficients and add exponents of same variables:

3x² × 4x³ = 12x⁵

2a²b × 5ab³ = 10a³b⁴

Monomial × Polynomial

Use the distributive law — multiply monomial with each term:

3x(x² − 2x + 4)

= 3x·x² + 3x·(−2x) + 3x·4

= 3x³ − 6x² + 12x

Binomial × Binomial

Use FOIL or double distribution:

(x + 3)(x + 5)

= x(x + 5) + 3(x + 5)

= x² + 5x + 3x + 15

= x² + 8x + 15

General: Polynomial × Polynomial

Every term of one expression multiplies every term of the other:

(a + b)(c + d) = ac + ad + bc + bd

Number of product terms = (terms in first) × (terms in second)

Always combine like terms after multiplication to simplify the result.

Standard Algebraic Identities

An identity is an equation that is true for all values of the variables.

Identity I: (a + b)²

(a + b)² = a² + 2ab + b²

Example: (x + 5)² = x² + 10x + 25

Here a = x, b = 5, so 2ab = 2·x·5 = 10x

Identity II: (a − b)²

(a − b)² = a² − 2ab + b²

Example: (3y − 4)² = 9y² − 24y + 16

Here a = 3y, b = 4

Identity III: (a + b)(a − b)

(a + b)(a − b) = a² − b²

Example: (x + 7)(x − 7) = x² − 49

Numerical use: 103 × 97 = (100 + 3)(100 − 3) = 10000 − 9 = 9991

Why Identities Are Useful

  • Speed up multiplication of numbers close to a round number
  • Help in factorisation (Chapter 14)
  • Simplify complex expressions quickly
Verify: (a − b)² = (a + b)² − 4ab — these identities are interconnected!

Identity IV: (a + b + c)²

(a + b + c)² = a² + b² + c² + 2ab + 2bc + 2ca

Derivation

Let a + b + c = (a + b) + c

[(a + b) + c]² = (a+b)² + 2(a+b)c + c²

= a² + 2ab + b² + 2ac + 2bc + c²

= a² + b² + c² + 2ab + 2bc + 2ca ✓

Example 1

Expand (x + 2y + 3z)²

= x² + 4y² + 9z² + 2(x)(2y) + 2(2y)(3z) + 2(3z)(x)

= x² + 4y² + 9z² + 4xy + 12yz + 6zx

Example 2 (Finding expression value)

If a + b + c = 7 and ab + bc + ca = 11, find a² + b² + c²

Use: (a+b+c)² = a²+b²+c² + 2(ab+bc+ca)

49 = a²+b²+c² + 2(11)

a²+b²+c² = 49 − 22 = 27

Important Note

The identity has exactly 6 terms on the right side: three squared terms and three cross-product terms (each multiplied by 2).

The three cross terms: 2ab + 2bc + 2ca, not 2ab + 2ac + 2bc — order cyclic (a→b→c→a).

Chapter Summary – Algebraic Expressions and Identities

Key Concepts

  • Terms are separated by + or −; factors are multiplied within a term
  • Coefficient = numerical factor; degree = highest power
  • Like terms have identical variable parts — only like terms can be added/subtracted
  • Multiplication: distribute every term of one expression over every term of the other
  • An identity holds for all values of variables

All Four Standard Identities

(a + b)² = a² + 2ab + b²

(a − b)² = a² − 2ab + b²

(a + b)(a − b) = a² − b²

(a + b + c)² = a² + b² + c² + 2ab + 2bc + 2ca

Quick Tips

  • Use Identity III for quick multiplication near round numbers
  • Identities I & II: middle term is always ±2ab
  • These identities reappear in factorisation and quadratic equations
