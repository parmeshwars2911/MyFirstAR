Data Handling

Chapter 5 · Grade 8 Mathematics

Data handling is the process of collecting, organising, displaying, and interpreting information (data). From sports scores to weather records, data is everywhere. In this chapter we learn to represent data in tables and graphs, and to calculate the probability of events.

Data Collection and Organisation

Data is a collection of facts, numbers, or observations gathered for analysis. Raw data is data in its original, unorganised form.

Frequency Distribution Table

A frequency is the number of times a particular value occurs. A frequency distribution table organises data by listing each value with its frequency and uses tally marks for counting.

Example

Marks scored by 10 students: 3, 5, 4, 3, 5, 5, 3, 4, 3, 5

MarkTallyFrequency
3IIII4
4II2
5IIII4
Total10

Key Terms

  • Observation: each individual data point
  • Frequency: count of how many times a value occurs
  • Tally marks: quick counting marks (IIII = 4, then a diagonal for 5)
  • Array: data arranged in ascending or descending order
  • Range: difference between largest and smallest values

Organising raw data into a frequency table helps identify patterns, the most common value (mode), and the spread of the data.

Grouped Data and Class Intervals

When data values span a wide range, we group them into class intervals (also called class width or class size).

Key Terms

  • Class interval: a range of values, e.g. 0–10, 10–20 (lower limit–upper limit)
  • Class size: upper limit minus lower limit (e.g. 10–0 = 10)
  • Class mark: midpoint of a class interval
  • Cumulative frequency: running total of frequencies up to a class
Class Mark = (Lower Limit + Upper Limit) / 2

Note on class limits: In the class interval 20–40, the convention is that 20 is included but 40 is not (40 goes in the next class). This is called an exclusive or continuous class interval. This ensures no value falls in two classes.

Histograms and Bar Graphs

Bar Graph

Used for discrete (categorical) data. Each category is represented by a separate bar.

  • Bars are separated by gaps (the gaps show they are distinct categories)
  • Width of all bars is the same; height represents frequency
  • X-axis: categories; Y-axis: frequency
  • Example: favourite sports, number of students in each class

Steps to draw:

  1. Draw two perpendicular axes
  2. Mark categories on x-axis with equal spacing
  3. Mark frequency scale on y-axis
  4. Draw bars of equal width with height = frequency; leave gaps between bars
  5. Label axes and give a title

Histogram

Used for continuous (grouped) data. Bars share boundaries — no gaps.

  • Bars are adjacent with no gaps — class intervals are continuous
  • X-axis: class intervals (continuous scale); Y-axis: frequency
  • Area of each bar is proportional to frequency
  • Example: height of students, scores in an exam

Steps to draw:

  1. Draw two perpendicular axes
  2. Mark class intervals on x-axis as a continuous scale
  3. Mark frequency scale on y-axis
  4. Draw bars touching each other; height = frequency
  5. Label axes and give a title

Key difference: Bar graph has gaps (discrete); histogram has no gaps (continuous).

Pie Charts (Circle Graphs)

A pie chart shows how a total is divided among different categories using sectors of a circle. The full circle = 360° = the total of all values.

Angle for a component = (Value of component / Total value) × 360°

Worked Example

In a survey of 240 students, their favourite sports are: Cricket = 60, Football = 80, Basketball = 40, Badminton = 60.

Total = 240 students
Cricket angle = (60 / 240) × 360° = 90°
Football angle = (80 / 240) × 360° = 120°
Basketball angle = (40 / 240) × 360° = 60°
Badminton angle = (60 / 240) × 360° = 90°
Total = 90 + 120 + 60 + 90 = 360° ✓

Steps to Draw a Pie Chart

  1. Calculate the angle for each component using the formula above
  2. Draw a circle of suitable radius
  3. Draw a radius to start; use a protractor to measure and draw each sector angle
  4. Label each sector with the category name and percentage or angle
  5. Shade or colour sectors differently; add a legend if needed
Percentage for a component = (Value / Total) × 100%

Probability

Probability measures how likely an event is to occur. It is a number between 0 and 1.

P(E) = Number of favourable outcomes / Total number of possible outcomes

Key Terms

  • Experiment: an action with uncertain outcomes (e.g. tossing a coin)
  • Outcome: a possible result of an experiment
  • Sample space (S): the set of all possible outcomes
  • Event (E): a specific outcome or set of outcomes we are interested in
  • Favourable outcomes: outcomes that satisfy the event

Range of Probability

0 ≤ P(E) ≤ 1
  • P(E) = 0: the event is impossible
  • P(E) = 1: the event is certain
  • P(E) + P(not E) = 1

Examples

Tossing a fair coin:

Sample space S = {H, T}; total outcomes = 2

P(Heads) = 1/2    P(Tails) = 1/2

Rolling a fair die:

Sample space S = {1, 2, 3, 4, 5, 6}; total outcomes = 6

P(even number) = 3/6 = 1/2
P(getting 4) = 1/6
P(number > 4) = 2/6 = 1/3

Drawing a card from a deck:

Total outcomes = 52

P(Ace) = 4/52 = 1/13
P(Heart) = 13/52 = 1/4

Summary: Data Handling

Key Formulas

Class Mark = (Lower Limit + Upper Limit) / 2
Pie Chart Angle = (Value / Total) × 360°
Percentage = (Value / Total) × 100%
P(E) = Favourable Outcomes / Total Outcomes
P(E) + P(not E) = 1

Types of Graphs

  • Bar graph: discrete data, bars with gaps
  • Histogram: continuous/grouped data, bars without gaps
  • Pie chart: parts of a whole, uses angles out of 360°

Data Organisation

  • Raw data → array → frequency table → grouped frequency table
  • Tally marks for counting (groups of 5)
  • Class interval: lower limit to upper limit
  • Cumulative frequency: running total

Probability Facts

  • 0 ≤ P(E) ≤ 1 always
  • P(impossible event) = 0
  • P(certain event) = 1
  • Complementary events: P(E) + P(E') = 1
  • Equal likelihood: when all outcomes are equally probable
