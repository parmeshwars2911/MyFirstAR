Introduction to Graphs

Chapter 15 · Grade 8 Mathematics

Graphs give a visual picture of data and relationships — turning numbers into shapes that reveal patterns, trends, and connections at a glance.

Topics covered: Bar graphs · Pie charts · Line graphs · Coordinate system · Plotting points · Linear graphs · Distance-time graphs

Bar Graphs, Pie Charts, and Line Graphs

Bar Graph

Uses rectangular bars to compare quantities across different categories.

  • Simple bar graph: One bar per category
  • Double bar graph: Two bars per category for comparison

Best used for: Comparing discrete categories (e.g., marks in different subjects, population of cities).

Key reading skill: Height of bar = value. Compare bar heights to find highest, lowest, difference.

Pie Chart (Circle Graph)

Shows parts of a whole as sectors of a circle.

Angle of sector = (Value / Total) × 360°

Best used for: Showing percentage share or composition (e.g., budget breakdown, percentage of students in each section).

Line Graph

Plots data points connected by line segments to show change over time or a continuous variable.

  • Best used for: Trends over time (temperature over days, rainfall over months, stock prices)
  • Rising line → increasing; falling line → decreasing; flat line → no change
  • Steep slope → rapid change; gentle slope → slow change

Choosing the Right Graph

Comparison: Bar graph

Parts of whole: Pie chart

Change over time or trend: Line graph

A misleading graph uses a non-zero y-axis start, which exaggerates differences — always check the axis scale before drawing conclusions!

The Coordinate System

A Cartesian coordinate system (named after René Descartes) uses two perpendicular number lines to locate every point on a plane.

Key Components

x-axis: Horizontal number line

y-axis: Vertical number line

Origin (O): Point where x-axis and y-axis cross; coordinates (0, 0)

Coordinates: Written as (x, y) — x is horizontal distance from origin (abscissa), y is vertical distance (ordinate).

The Four Quadrants

Quadrant I: x > 0, y > 0 (top-right)

Quadrant II: x < 0, y > 0 (top-left)

Quadrant III: x < 0, y < 0 (bottom-left)

Quadrant IV: x > 0, y < 0 (bottom-right)

Reading Coordinates

For a point P at (3, 5): start at origin, move 3 units right, then 5 units up.

For Q at (−2, 4): move 2 units left, then 4 units up (Quadrant II).

For R at (−3, −2): move 3 left, 2 down (Quadrant III).

For S at (4, −1): move 4 right, 1 down (Quadrant IV).

Points on Axes

A point on the x-axis has y-coordinate = 0: e.g., (5, 0)

A point on the y-axis has x-coordinate = 0: e.g., (0, −3)

The origin is on both axes: (0, 0)

Always write coordinates in order: (x first, y second). "Abscissa" = x-coordinate; "Ordinate" = y-coordinate.

Plotting Points on a Graph

Steps to Plot a Point (x, y)

  1. Draw and label the x-axis and y-axis on graph paper
  2. Mark equal intervals on both axes with a suitable scale
  3. Starting from the origin, count x units along the x-axis (right if positive, left if negative)
  4. From that position, count y units vertically (up if positive, down if negative)
  5. Mark the point with a dot and label it with its coordinates

Example: Plot A(1,1), B(2,3), C(4,5) and check collinearity

Slope AB = (3−1)/(2−1) = 2

Slope BC = (5−3)/(4−2) = 1

Slopes differ → A, B, C are NOT collinear (not on one line).

Plotting from a Table of Values

Given the relationship y = 2x:

x01234
y = 2x02468

Plot: (0,0), (1,2), (2,4), (3,6), (4,8). Connect → straight line through origin!

Real-World Applications of Coordinate Graphs

  • Maps: x = east-west position, y = north-south position
  • GPS: latitude (y) and longitude (x)
  • Computer screens: pixels located by (column, row)
  • Physics experiments: plotting experimental data to find relationships
Any two distinct points uniquely determine a straight line. Plot at least three points to be sure your graph is correct.

Linear Graphs: y = mx and Applications

A linear graph is a straight line. When it passes through the origin, it represents direct proportion:

y = mx (m = slope = constant of proportionality)

Understanding the Slope m

m = Δy / Δx = (y₂ − y₁) / (x₂ − x₁)

m > 0: line rises (positive slope)

m < 0: line falls (negative slope)

m = 0: horizontal line (constant y)

Larger |m| → steeper line.

Cost vs Quantity

Cost of apples at ₹15 per kg: C = 15q

q (kg)0123
C (₹)0153045

Straight line through origin; slope = 15.

Temperature Conversion

F = (9/5)C + 32

This is linear but does NOT pass through origin (32°F ≠ 0 when C = 0).

Still a straight line; slope = 9/5 = 1.8

Simple Interest

For fixed Principal P and rate R: I = (P × R/100) × T

I varies directly with T → straight line through origin; slope = PR/100.

Side vs Perimeter of a Square

P = 4s

Slope = 4. Each 1 cm increase in side adds 4 cm to perimeter.

All directly proportional relationships produce linear graphs through the origin. The slope equals the proportionality constant.

Reading Distance-Time Graphs; Speed = Slope

A distance-time graph plots distance on the y-axis and time on the x-axis. The slope of the line equals speed.

Interpreting Segments

Steep positive slope: High speed (moving fast)

Gentle positive slope: Low speed (moving slowly)

Horizontal line (slope = 0): Stationary (at rest)

Line slanting back down: Returning toward start point

Calculating Speed

Speed = Distance / Time = slope = Δy / Δx

Example: A vehicle moves from 40 km to 160 km in the time period 1h to 4h.

Speed = (160 − 40) / (4 − 1) = 120/3 = 40 km/h

A Complete Journey Story

Segment 1 (0–2h): Distance 0 → 100 km. Slope = 50 km/h

Segment 2 (2h–3h): Distance stays at 100 km. At rest (rest stop).

Segment 3 (3h–5h): Distance 100 → 160 km. Slope = 30 km/h (slower)

Total journey: 160 km in 5 hours

Average speed = 160/5 = 32 km/h

Average speed = slope of line from (0,0) to (5,160).

Average vs Instantaneous Speed

Average speed = total distance ÷ total time (ignores stops). Instantaneous speed = slope at any one moment.

A curved D-T graph means changing speed (acceleration). Grade 8 focuses on straight-line segments (constant speed).

Chapter Summary – Introduction to Graphs

Types of Graphs

  • Bar graph: Compare categories; height = value
  • Pie chart: Parts of a whole; sector angle = (part/total) × 360°
  • Line graph: Trends over time
  • Coordinate graph: Relationship between two quantities

Coordinate System

  • Origin (0,0); x-axis (horizontal); y-axis (vertical)
  • Four quadrants: I (+,+); II (−,+); III (−,−); IV (+,−)
  • Point (x, y): x first (abscissa), y second (ordinate)

Linear Graphs

y = mx (line through origin; m = slope)

Slope m = Δy / Δx = rise / run

Steeper line = larger slope = faster rate of change.

Distance-Time Graphs

Slope = Speed = Distance ÷ Time

  • Steep positive slope → high speed
  • Horizontal segment → at rest (speed = 0)
  • Average speed = slope of line joining start and end of whole journey

Average Speed = Total Distance / Total Time
