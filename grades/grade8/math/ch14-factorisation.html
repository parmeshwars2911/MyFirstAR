Factorisation

Chapter 14 · Grade 8 Mathematics

Factorisation is the reverse of expansion — breaking a polynomial into a product of simpler expressions (its factors).

Topics covered: Common factor method · Regrouping · Factorisation using identities · Division of algebraic expressions · Division of polynomial by polynomial

Factorisation by Common Factor Method

Find the Highest Common Factor (HCF) of all terms and take it outside.

Steps

  1. Find the HCF of numerical coefficients
  2. Find the common variable factors (lowest power present in all terms)
  3. Take the HCF out as a common factor
  4. Write the remaining expression in brackets

Examples

Example 1: 6x² + 9x

HCF of 6 and 9 = 3; common variable = x

= 3x(2x + 3)

Example 2: 12a²b + 8ab² − 4ab

HCF = 4ab

= 4ab(3a + 2b − 1)

More Examples

Example 3: x(y + z) + 3(y + z)

Common factor = (y + z)

= (y + z)(x + 3)

Example 4: 15p²q − 20pq²r

HCF of 15 and 20 = 5; HCF of p²q and pq² = pq

= 5pq(3p − 4qr)

Verify!

Always expand your answer to check it equals the original expression.

5pq(3p − 4qr) = 15p²q − 20pq²r ✓

Factorisation is the reverse of multiplication. If A × B = C, then C factorises as A × B.

Factorisation by Regrouping

When there is no single factor common to all terms, try rearranging and grouping terms to create common factors.

Steps

  1. Look for pairs (or groups) of terms that share a common factor
  2. Rearrange if needed to bring such pairs together
  3. Factor each group
  4. Take the resulting common binomial factor out

Example 1

Factorise: xy + 2y + 3x + 6

Group: (xy + 2y) + (3x + 6)

= y(x + 2) + 3(x + 2)

= (x + 2)(y + 3)

Example 2

Factorise: 6ab − b² + 12ac − 2bc

Group: (6ab + 12ac) + (−b² − 2bc)

= 6a(b + 2c) − b(b + 2c)

= (b + 2c)(6a − b)

Example 3

Factorise: x³ − 2x² + x − 2

= x²(x − 2) + 1(x − 2)

= (x − 2)(x² + 1)

Try different groupings if the first attempt doesn't give a common binomial factor — the same expression can be grouped in more than one way.

Factorisation Using Algebraic Identities

The standard identities from Chapter 9 can be used in reverse to factorise expressions.

Identity I reversed: Perfect Square Trinomial

a² + 2ab + b² = (a + b)²

Example: x² + 6x + 9 = x² + 2(x)(3) + 3² = (x + 3)²

Identity II reversed: Perfect Square Trinomial

a² − 2ab + b² = (a − b)²

Example: 4y² − 12y + 9 = (2y)² − 2(2y)(3) + 3² = (2y − 3)²

Identity III reversed: Difference of Squares

a² − b² = (a + b)(a − b)

Example 1: x² − 25 = x² − 5² = (x + 5)(x − 5)

Example 2: 9m² − 16n² = (3m)² − (4n)² = (3m + 4n)(3m − 4n)

Example 3: 49 − y² = (7 + y)(7 − y)

Recognising the Pattern

  • Perfect square: check if first and last terms are perfect squares, and middle term = ±2 × √(first) × √(last)
  • Difference of squares: exactly two terms, both perfect squares, connected by minus
Common mistake: a² + b² does NOT factorise over integers. Only a² − b² (difference) factorises.

Division of Algebraic Expressions

Monomial ÷ Monomial

Divide coefficients and subtract exponents of same variables.

Example 1: 12x³ ÷ 4x = 3x²

Example 2: −15a²b³ ÷ 5ab = −3ab²

Example 3: 24p²q³r ÷ 6pqr = 4pq²

Polynomial ÷ Monomial

Divide each term of the polynomial by the monomial.

Example: (6x³ − 4x² + 8x) ÷ 2x

= 6x³/2x − 4x²/2x + 8x/2x

= 3x² − 2x + 4

More Examples (Polynomial ÷ Monomial)

Example 2: (9a²b² − 6ab³ + 3a³b) ÷ 3ab

= 9a²b²/3ab − 6ab³/3ab + 3a³b/3ab

= 3ab − 2b² + a²

Key Rules

  • Positive ÷ Positive = Positive
  • Negative ÷ Negative = Positive
  • Positive ÷ Negative = Negative (and vice versa)
  • For variables: xᵐ ÷ xⁿ = xᵐ⁻ⁿ
Division of a polynomial by a monomial: split and divide term by term. Never cancel only part of a term!

Division of Polynomial by Polynomial; Finding Errors

Polynomial ÷ Polynomial

Factorise both, then cancel common factors.

Example 1: (x² + 5x + 6) ÷ (x + 2)

Factorise numerator: x² + 5x + 6 = (x + 2)(x + 3)

= (x + 2)(x + 3) ÷ (x + 2) = (x + 3)

Example 2: (a² − b²) ÷ (a + b)

= (a + b)(a − b) ÷ (a + b) = (a − b)

Example 3: (y² − 7y + 12) ÷ (y − 3)

Factorise: (y − 3)(y − 4) ÷ (y − 3) = y − 4

Finding Errors in Algebra

Spot the mistake in each of these common errors:

Error 1: 3(x + 4) = 3x + 4

Correct: 3(x + 4) = 3x + 12 (must multiply 3 by every term)

Error 2: (x + y)² = x² + y²

Correct: (x + y)² = x² + 2xy + y² (forgot the middle term)

Error 3: (x + 5)(x + 3) = x² + 15

Correct: = x² + 8x + 15 (must expand all four products)

Error 4: 7x + 5/7x = 5

Cannot cancel 7x from only one term of numerator.

Always factorise before cancelling — never cancel individual terms across a + or − sign!

Chapter Summary – Factorisation

Factorisation Methods

  • Common factor: Take HCF outside brackets
  • Regrouping: Group terms to create common binomial factors
  • Identity I: a² + 2ab + b² = (a+b)²
  • Identity II: a² − 2ab + b² = (a−b)²
  • Identity III: a² − b² = (a+b)(a−b)

Division of Algebraic Expressions

Monomial ÷ Monomial: divide coefficients, subtract exponents

Polynomial ÷ Monomial: divide each term separately

Polynomial ÷ Polynomial: factorise then cancel

Common Pitfalls

  • a² + b² ≠ (a+b)²
  • (a+b)² ≠ a² + b² (forget 2ab)
  • Cannot cancel part of a sum/difference
  • Always verify by re-expanding
