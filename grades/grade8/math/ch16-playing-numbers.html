Playing with Numbers

Chapter 16 · Grade 8 Mathematics

Numbers have deep patterns hidden inside them. Algebra helps us reveal those patterns — explaining why tricks work, why divisibility rules hold, and how to crack digit puzzles.

Topics covered: Numbers in general form · Digit games · Divisibility rules · Cryptarithmetic · Word problems

Numbers in General Form

Any number can be expressed algebraically using its digits. This lets us prove why number tricks and divisibility rules work.

2-Digit Number

A 2-digit number with tens digit a and units digit b:

Number = 10a + b

Example: 47 = 10(4) + 7 = 47 ✓

Reversed number: 10b + a

Sum with reverse:

(10a + b) + (10b + a) = 11(a + b)

Always divisible by 11!

Difference with reverse:

(10a + b) − (10b + a) = 9(a − b)

Always divisible by 9!

3-Digit Number

A 3-digit number with hundreds digit a, tens digit b, units digit c:

Number = 100a + 10b + c

Example: 352 = 100(3) + 10(5) + 2 ✓

Three cyclic permutations:

100a+10b+c

100b+10c+a

100c+10a+b

Sum of all three:

= 111(a+b+c) = 3 × 37 × (a+b+c)

Always divisible by 3, 37, and 111!

Writing numbers in general form (using algebra) turns observations into proofs.

Games with Numbers: Reversing and Summing Digits

Game 1: Reversing a 2-Digit Number — Sum

Think of a 2-digit number. Add it to its reverse. Divide by 11. You get the sum of digits — always!

Proof: (10a+b) + (10b+a) = 11(a+b)

Divided by 11 = a + b (sum of digits) ✓

Try it: 73 + 37 = 110 = 11 × (7+3) = 11 × 10

Game 2: Reversing a 2-Digit Number — Difference

Proof: (10a+b) − (10b+a) = 9(a−b)

Always a multiple of 9.

Example: 84 − 48 = 36 = 9 × (8−4) = 9 × 4 ✓

Game 3: Three-Digit Cyclic Rotation

Write a 3-digit number abc, then its cyclic rotations bca and cab. Sum all three. The result is always 111 × (a+b+c).

Example: 197, 971, 719

197 + 971 + 719 = 1887

1887 ÷ 111 = 17 = 1+9+7 ✓

1887 ÷ 37 = 51 = 3 × (1+9+7) ✓

Why Tricks Work

All such "magic" results follow from the general form. Algebra reveals the hidden structure — the "magic" is just mathematics!

Next time you see a number trick, write the number as 10a+b (or 100a+10b+c) and work through the algebra — you'll understand exactly why it works.

Divisibility Rules

These rules let you test divisibility without actually dividing. All can be proved using the general form of numbers.

Divisibility by 2, 5, 10

By 2: Last digit is 0, 2, 4, 6, or 8 (even).

Proof: 10a+b; 10a is always even, so only b matters.

By 5: Last digit is 0 or 5.

By 10: Last digit is 0.

Divisibility by 4

The last two digits form a number divisible by 4.

Example: 5236 → last two digits 36; 36 ÷ 4 = 9 ✓

Example: 5238 → last two digits 38; 38 ÷ 4 = 9.5 ✗

Divisibility by 3

Sum of all digits is divisible by 3.

Example: 1,234,563 → 1+2+3+4+5+6+3 = 24; 24÷3 = 8 ✓

Divisibility by 9

Sum of all digits is divisible by 9.

Example: 729 → 7+2+9 = 18; 18÷9 = 2 ✓

Proof (2-digit): 10a+b = 9a + (a+b). 9a is divisible by 9, so it reduces to checking a+b.

Divisibility by 11

The alternating digit sum (units − tens + hundreds − …) is divisible by 11 (or equals 0).

Example: 2728 → 8−2+7−2 = 11 ✓

Example: 5082 → 2−8+0−5 = −11 ✓ (negative is fine)

Example: 1001 → 1−0+0−1 = 0 ✓ (0 is divisible by 11)

Rules for 3 and 9 work because 10 ≡ 1 (mod 3) and (mod 9) — so all powers of 10 contribute just their digit value.

Letters for Digits (Cryptarithmetic)

In cryptarithmetic puzzles, letters replace digits in arithmetic sums. Your task: find the unique digit each letter represents.

Rules of Cryptarithmetic

  • Each letter represents a unique single digit (0–9)
  • Different letters must represent different digits
  • The leading digit of any multi-digit number cannot be 0
  • Use column-by-column logic and carry constraints

Strategy

  1. Look at the leftmost column — carries and leading-digit constraints limit options
  2. Work column by column (units → tens → hundreds)
  3. Use divisibility or range constraints to narrow digits
  4. Try candidates systematically and eliminate contradictions

Example 1: AB + BA = CBC

In general form: (10A+B) + (10B+A) = 100C+10B+C

11(A+B) = 101C + 10B

Since digits are 0–9, max LHS = 11×18 = 198, so C = 1.

11A + B = 101. With A ≤ 9: A = 9, B = 2.

Check: 92 + 29 = 121 = CBC (C=1, B=2) ✓

Example 2: ON × ON = WON

A 2-digit number squared = a 3-digit number starting with W, O, N.

So O, N, W are all different digits. 2-digit perfect squares in 100s: 100–999 → ON between 10–31. Try ON = 11 to 31 and check pattern.

Cryptarithmetic combines algebra, number theory, and logic — a beautiful puzzle format used in math olympiads.

Test of Divisibility Puzzles and Word Problems

Finding Missing Digits

Problem 1: Find A so that 31A5 is divisible by 3.

Sum = 3+1+A+5 = 9+A must be divisible by 3.

9 is divisible by 3, so A can be 0, 3, 6, or 9.

Problem 2: Find A so that 7A3 is divisible by 9.

Sum = 7+A+3 = 10+A must be divisible by 9.

A = 8 (since 10+8 = 18 = 2×9) ✓

Check: 783 ÷ 9 = 87 ✓

Problem 3: For what values of A is 64A3 divisible by 11?

Alternating sum: 3−A+4−6 = 1−A must be divisible by 11.

1−A = 0 → A = 1 or 1−A = −11 → A = 12 (impossible).

So A = 1. Check: 6413; alt sum = 3−1+4−6 = 0 ✓

Word Problems

Problem 1: The sum of a 2-digit number and its reverse is 110. Their difference is 36. Find the number.

Sum: 11(a+b) = 110 → a+b = 10

Difference: 9(a−b) = 36 → a−b = 4

Solving: a = 7, b = 3 → 73

Verify: 73+37 = 110 ✓; 73−37 = 36 ✓

Problem 2: A 2-digit number is 4 times the sum of its digits. If 9 is added, the digits reverse. Find the number.

Number = 10a+b = 4(a+b) → 6a = 3b → b = 2a

Reversed: 10a+b+9 = 10b+a → 9a−9b = −9 → b−a = 1

b = 2a and b−a = 1 → a = 1, b = 2 → 12

Verify: 12 = 4(1+2) = 12 ✓; 12+9 = 21 (reversed) ✓

Always verify your answer by substituting back into the original problem — both conditions must be satisfied.

Chapter Summary – Playing with Numbers

General Forms

2-digit (ab) = 10a + b

3-digit (abc) = 100a + 10b + c

Sum with reverse (2-digit) = 11(a+b)

Difference with reverse = 9(a−b)

Sum of 3 cyclic rotations = 111(a+b+c)

Divisibility Rules

By 2: last digit even

By 3: digit sum divisible by 3

By 4: last two digits divisible by 4

By 5: last digit 0 or 5

By 9: digit sum divisible by 9

By 10: last digit 0

By 11: alternating digit sum divisible by 11

Cryptarithmetic

  • Each letter = unique digit (0–9)
  • Leading digit ≠ 0
  • Use column logic, carries, and range constraints
  • Verify answer in original sum

Problem-Solving Approach

  1. Write the number(s) in general form
  2. Set up algebraic equations from the given conditions
  3. Solve the system and check digit constraints (0–9, integer, not leading zero)
  4. Verify all conditions are satisfied
The central theme: algebra explains why number properties hold. Every "magic" number trick is a theorem in disguise!
