Linear Equations in One Variable

Chapter 2 · Grade 8 Mathematics

A linear equation in one variable is the simplest type of equation in algebra. It involves a single unknown raised to the first power. Learning to solve such equations builds the foundation for all higher-level algebra and real-world problem solving.

Definition and Standard Form

A linear equation in one variable is an equation that can be written in the form:

ax + b = 0    where a ≠ 0, and a, b are real numbers

The variable x appears with power exactly 1 (linear means the graph is a straight line). There is exactly one solution for any such equation.

Linear Equations (Examples)

  • 2x + 5 = 13 — standard linear form
  • 3x = 9 — b = 0
  • x/4 - 2 = 1 — variable in denominator of fraction
  • 5(x - 1) = 2x + 4 — can be simplified to linear form
  • 7 - x = 3x + 1 — variables on both sides

Not Linear (Non-Examples)

  • x² + 2x = 5 — power of x is 2 (quadratic)
  • x³ = 8 — power of x is 3 (cubic)
  • √x = 4 — x has power 1/2
  • 1/x = 3 — x is in the denominator
  • xy = 6 — two variables

Key point: The highest power of the variable in a linear equation is 1. An equation in one variable has exactly one unknown and (usually) one solution.

Solving Linear Equations

The goal is to isolate the variable on one side. Two key operations maintain the equality:

  • Adding or subtracting the same number on both sides.
  • Multiplying or dividing both sides by the same non-zero number.

Transposition Rule

When a term is moved from one side to the other, its sign changes. (Addition becomes subtraction and vice versa; multiplication becomes division.)

If a + b = c, then a = c - b    (b is transposed, sign changes)

Worked Example: Solve 2x + 5 = 13

2x + 5 = 13
2x = 13 - 5    (transpose +5, it becomes -5)
2x = 8
x = 8 / 2    (divide both sides by 2)
x = 4

Verification: Substitute x = 4: 2(4) + 5 = 8 + 5 = 13. Correct!

Worked Example: Solve 3x/4 - 2 = 7

3x/4 = 7 + 2 = 9
3x = 9 × 4 = 36
x = 36 / 3 = 12

Equations with Variables on Both Sides

When the variable appears on both sides of the equation, collect all variable terms on one side and all constant terms on the other side.

Strategy

  1. Move all terms containing the variable to the left side.
  2. Move all constant terms to the right side.
  3. Simplify and solve for the variable.

Worked Example: Solve 3x + 4 = 5x - 2

3x + 4 = 5x - 2
3x - 5x = -2 - 4    (transpose 5x to left, 4 to right)
-2x = -6
x = -6 / (-2) = 3

Verification: LHS = 3(3) + 4 = 13; RHS = 5(3) - 2 = 13. Correct!

Worked Example: Solve 2(x + 3) = 5x - 9

2x + 6 = 5x - 9    (expand the bracket)
2x - 5x = -9 - 6
-3x = -15
x = 5

Note: Always expand brackets before transposing terms. Remember that transposing changes the sign of the term being moved.

Reducing Equations to Linear Form

Some equations look like fractions set equal to each other. We use cross-multiplication to convert them to a standard linear form.

If a/b = c/d    then    a × d = b × c

Worked Example: Solve (x + 1) / (2x + 3) = 3 / 8

(x + 1) / (2x + 3) = 3 / 8
Cross-multiply: 8(x + 1) = 3(2x + 3)
8x + 8 = 6x + 9
8x - 6x = 9 - 8
2x = 1
x = 1/2

Verification: LHS = (1/2 + 1)/(2×1/2 + 3) = (3/2)/(4) = 3/8 = RHS. Correct!

Worked Example: Solve (2x - 1) / 5 = (x + 3) / 3

3(2x - 1) = 5(x + 3)
6x - 3 = 5x + 15
6x - 5x = 15 + 3
x = 18

Remember: Cross-multiplication is only valid when denominators are non-zero expressions. Always check your answer by substituting back.

Word Problems

Linear equations are powerful tools for solving real-life problems. The key is to translate the words into an equation.

Age Problem

The sum of ages of a father and son is 40. The father is three times as old as the son. Find their ages.

Let son's age = x
Father's age = 3x
x + 3x = 40
4x = 40  ⇒  x = 10
Son = 10, Father = 30

Number Problem

One number is 4 more than twice another. Their sum is 25. Find them.

Let one number = x
Other = 2x + 4
x + 2x + 4 = 25
3x = 21  ⇒  x = 7
Numbers: 7 and 18

Perimeter Problem

The perimeter of a rectangle is 50 cm. Its length is 5 cm more than its breadth. Find the dimensions.

Let breadth = x, length = x + 5
2(x + x + 5) = 50
2(2x + 5) = 50
4x + 10 = 50
4x = 40  ⇒  x = 10
Breadth = 10 cm, Length = 15 cm

Angle Problem

Two supplementary angles differ by 30°. Find both angles.

Let angles = x and x + 30
x + x + 30 = 180
2x = 150  ⇒  x = 75°
Angles: 75° and 105°

Summary: Linear Equations in One Variable

Standard Form

ax + b = 0    (a ≠ 0)

Key Methods

  • Transposition: move terms across the equals sign, changing sign
  • Variables on both sides: collect variable terms on one side, constants on other
  • Cross-multiplication: a/b = c/d ⇒ ad = bc
  • Expansion: expand brackets before transposing

Golden Rule

Whatever you do to one side, do the same to the other side.

Steps to Solve

  1. Expand all brackets
  2. If fractions, cross-multiply or multiply both sides by LCM
  3. Collect variable terms on LHS
  4. Collect constants on RHS
  5. Divide both sides by the coefficient of the variable
  6. Verify by substituting back

Word Problem Strategy

  1. Identify the unknown — call it x
  2. Express all quantities in terms of x
  3. Form the equation from the given condition
  4. Solve and interpret the answer
